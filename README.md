# Stepan Userbot 🤖

Юзербот для Telegram на Python (Telethon). Ты входишь в свой аккаунт
(номер → код → пароль), а по команде **`.menu`** твоё сообщение
превращается в красивое меню «Stepan Userbot» с кнопками.

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Зайди на https://my.telegram.org → *API development tools* — получи `api_id` и `api_hash`.
2. Открой `config.py` и вставь свои значения:

```python
API_ID = 12345678            # твой api_id
API_HASH = "your_api_hash"   # твой api_hash
```

## Запуск

```bash
python stepan_userbot.py
```

При первом запуске бот спросит:
- **номер телефона** (например `+79991234567`)
- **код** из служебного сообщения Telegram
- **пароль**, если включена двухэтапная авторизация (2FA)

Данные сохранятся в файл `stepan_userbot.session` — повторно вводить их не нужно.

## Команды

| Команда | Что делает |
|---------|------------|
| `.menu` | 👉 заменяет это сообщение на **меню Stepan Userbot** с кнопками |
| `.ping` | показывает задержку (Понг) |
| `.help` | список команд |
| `.id`   | твой ID и ID чата |
| `.off`  | удалить сообщение |

Кнопки в меню («🔄 Обновить», «📋 Помощь», «🏓 Пинг») тоже работают —
при нажатии отправляют соответствующую команду.

## Как это работает

Бот слушает исходящие сообщения. Когда ты пишешь `.menu`, обработчик
событий `events.NewMessage(pattern=r"^\.menu")` ловит это сообщение
и через `event.edit()` **редактирует его же**, подставляя текст меню
и inline-кнопки. Никаких отдельных сообщений — именно твоё сообщение
превращается в меню.

⚠️ **Важно:** юзербот работает от имени твоего аккаунта. Не используй
его для спама — Telegram может ограничить или забанить аккаунт.
